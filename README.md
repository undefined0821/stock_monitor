# 实时股票监控平台 v3

监控你的 A 股持仓，**仅在交易日（周一~周五）运行**。

## 功能
- **🚨 异动提醒（置顶）**：实时滚动预警，置顶展示
- **📈 上证指数 1 小时后趋势预测（最上方）**：**每 5 秒刷新**（v3.10），只判「涨/跌」方向 + 概率，并附**大盘分时图**辅助；AI 融合降频至 120 秒一次，两次 AI 之间用纯启发式随行情 5 秒更新
- **🔥 开盘前涨停趋势（9:25:02 首扫，持续到 9:29 每分钟更新）**：自动扫描**全市场主板**，排除你的持仓/ST/观察池，找出 **5 只**最可能涨停的未持有强势股，并标注涨停概率
  - 筛选条件：主板(排除创业板/北证)、流通市值≥37亿、股价≥8元、排除ST
  - **两段式**：9:25:02 首扫全市场(约1分钟)生成候选池，之后每分钟只对候选池重排，实时快
- **💼 持仓卡片（隐私保护）**：实时价/盈亏 + 🛑止损线 + 🟢补仓区1/2 + ✅止盈线 + ⛰压力位 + 涨停/跌停价 + 异动标签；卡片主色以**成本价 vs 实时价(盈亏)**为准（非昨收）；**浮动盈亏恒基于成本；当日盈亏分段计算**——开盘前持仓部分按上一交易日收盘、今日加仓部分按成本（加仓不抹除加仓前已有收益，也不把加仓亏损算成昨收收益）；右上角显示**所属细分题材涨跌**（题材名+平均涨跌幅+强弱排名）；**新增持仓经东方财富行业+名称自动归类，命中题材即自动显示芯片（无需手动纠错）**；已移除"持仓时长"；顶部「👁 小眼睛」可一键隐藏金额

- **🌐 大盘 & 题材资金动向**：三大指数 + 细分题材涨跌榜（CPO/PCB/纸业/白酒 等）+ 「题材拉/踩指数」（细分主线相对大盘偏离）
- **🔮 尾盘预测（15:00）**：下个交易日涨跌概率（大盘+个股）
- **🚀 尾盘高开潜力（收盘前 8 分钟）**：自动扫描**主板（排除涨停）**，选出 **5 只**下个交易日开盘高开概率最高的股票，并标注高开概率与置信度；高开判定收紧为 **gap≥0.5%**（不再把 +0.01% 噪声算命中），回测卡同时展示严格/宽松双命中率
- **🎯 预测回测总览（v3.10 新增）**：上证1小时 / 尾盘大盘 / 尾盘个股 / 盘前涨停 四个模块全部落盘回测（`pred_log.jsonl`），自动回填真实结果，展示各模块**命中率**与**校准偏差**（平均预测概率 − 实际发生率，衡量概率是否名副其实）
- **✅ 预测概率自动校准（v3.10.1 新增）**：四个 P1 模块概率随验证样本积累自动 Platt 校准（样本≥12 重拟合），使概率对齐真实命中率，实时输出与回测一致。
- **🔧 预测自动调参（v3.11.0 / v3.11.1）**：按实盘表现自动调决策阈值与打分权重，真正提升命中率（区别于仅校准概率）。含防过拟合门控，回填后自动重调，面板展示调参状态；尾盘高开潜力(v3.11.1)以 AUC 衡量纳入同一引擎。
- **🗄 本地日线库（v3.10 新增）**：每交易日 15:05 自动抓取当日完整日线（指数+持仓+自选+当日候选）落盘 `daily_bars.jsonl`，供回测按日期回溯；内置**定期清理**（保留 250 天 + 体积上限 120MB 双阈值，自动丢弃最旧数据防磁盘写满）

## 启动
```bash
bash run.sh          # 前台
# 或后台常驻
nohup bash run.sh > monitor.log 2>&1 &
```
访问 http://localhost:8800

## 关键点说明
- **数据源**：腾讯财经实时行情 `qt.gtimg.cn`（真实数据，无需 token）。本沙箱东方财富/新浪被封；腾讯日线接口 `ifzq.gtimg.cn` 部分时段不稳定（501），故 v3.10 起**自建本地日线库**（每交易日 15:05 自采），回测优先走本地库。
- **涨停扫描的历史条件受限**：你要求的"近一年涨停次数<15、昨日未涨停、5日振幅<17%"需历史数据，本地日线库积累满后即可支持，当前仍用**当日实时强度**（距涨停距离+量比+涨幅+委比）替代，并在界面注明。
- **预测回测闭环**：所有预测落盘 `pred_log.jsonl`，到期自动回填真实结果并累计 `pred_stats.json`；回测按"预测日期"从日线回溯，即使沙箱休眠跨天也不会拿错基准；腾讯日线故障时自动降级实时行情兜底。
- **候选池**：全市场主板首扫需约1分钟，构建期间接口即时返回"构建中"，完成后自动填充。
- 修改 `portfolio.json` 的 `take_profit_pct`/`pressure_pct`/`scan` 可自定义止盈/压力/筛选。

> 本平台为个人监控与异动辅助工具，所有预测/概率均基于规则与统计模型，**不构成投资建议**。

## ⚡ 性能基线（实测，沙箱 Ubuntu22.04 / Chromium / Python3.11）

尾盘高开潜力（gapup）已从「约 4 分钟且易卡死」优化到「约 2 秒稳定出结果」：

| 阶段 | 优化前 | 当前 |
|------|--------|------|
| `universe` 全市场扫描（3001 只） | 串行 8 只/请求，约 **173 秒** | 线程池并行 + 批量 40 只，**约 1 秒** |
| `top15` 拉分时算尾盘 | 串行，约 30-60 秒 | 线程池并行，**数秒** |
| AI 精修 | 本地模型逐只推理，**卡死/超时回退** | **默认跳过本地模型**（沙箱无 GPU 不稳定），仅远程 AI（无则回退启发式） |
| 端到端 | ~4 分钟 + 卡死 | **~2 秒**（`done, 5 rows`） |

> 优化点：行情抓取统一走 `fetch_tencent`，内部批量切分 + 线程池并发 + `requests.Session` 复用；全局共享线程池避免线程堆积；`/api/snapshot` 加超时保护防止接口挂起。**本地 AI 精修因沙箱环境不稳定已默认关闭**，如需恢复，配置远程 AI API 即可启用远程精修。

## ⚠️ 部署与数据保护（务必遵守）

`portfolio.json`、`gapup_log.jsonl`、`gapup_stats.json`、`gapup_weights_tuned.json`、`gapup_calib.json`、`pred_log.jsonl`、`pred_stats.json`、`daily_bars.jsonl` 是**用户运行时数据**（前端实时编辑 / 服务累积生成），已从 git 忽略，模板为 `portfolio.json.example`。

**发布必须用 `deploy.sh`，不要用 `publish.js` 直发：**

```bash
bash deploy.sh   # 先拉取线上持仓/回测数据 → 再部署，避免覆盖前端改动
```

严禁以下操作（会拿陈旧基线顶掉线上用户数据）：
- ❌ `git checkout -- portfolio.json` / `git commit -A`（会恢复或提交陈旧持仓）
- ❌ 直接 `node .../publish.js --dir .`（整目录覆盖式部署，本地旧文件会顶掉线上）

`/api/portfolio` GET 返回完整持仓（含 `buy_date`），便于 `deploy.sh` 忠实同步还原；服务启动时若数据文件缺失会自动从 `portfolio.json.example` 初始化 / 播种回测基线。
