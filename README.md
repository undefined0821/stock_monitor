# 实时股票监控平台 v3

监控你的 A 股持仓，**仅在交易日（周一~周五）运行**。

## 功能
- **🚨 异动提醒（置顶）**：实时滚动预警，置顶展示
- **📈 上证指数 1 小时后趋势预测**：每 5 秒刷新，只判「涨/跌」方向 + 概率，附大盘分时图；AI 融合降频至 120 秒
- **🔥 开盘前涨停趋势（9:25 首扫）**：全市场主板扫描，排除持仓/ST/观察池，找出最可能涨停的未持有强势股并标注概率（两段式：首扫建池 + 每分钟重排）
- **💼 持仓卡片（隐私保护）**：实时价/盈亏 + 止损线 + 补仓区 + 止盈线 + 压力位 + 涨停/跌停价 + 异动标签；主色以盈亏为准；右上角显示所属题材涨跌；新增持仓自动归类题材；「👁 小眼睛」一键隐藏金额
- **🌐 大盘 & 题材资金动向**：三大指数 + 细分题材涨跌榜 + 「题材拉/踩指数」
- **🔮 尾盘预测（15:00）**：下个交易日涨跌概率（大盘+个股）
- **🚀 尾盘高开潜力（收盘前 8 分钟）**：主板扫描（排除涨停），选下个交易日高开概率最高的股票并标注概率/置信度；高开判定收紧 gap≥0.5%，回测展示严格/宽松双命中率
- **🎯 预测回测总览**：四大预测模块全部落盘回测，自动回填真实结果，展示命中率与校准偏差
- **✅ 预测概率自动校准**：样本积累后自动 Platt 校准，概率对齐真实命中率
- **🔧 预测自动调参**：按实盘表现自动调决策阈值与打分权重，提升命中率（含防过拟合门控）
- **🔍 选股池（每日 14:25 自动扫描）**：全市场主板扫描取 TopN 推荐，逻辑加密封装（不在源码/前端暴露明细）；实时行情强预筛 + 本地日线库预热后零网络秒级出结果
- **🗄 本地日线库**：每交易日 15:05 自采当日完整日线落盘，供回测按日期回溯；体积上限 + 保留 250 天双阈值自动清理

## 启动
```bash
bash run.sh                 # 后台常驻(内部 python3.11 app.py)
nohup bash run.sh > monitor.log 2>&1 &   # 等价写法
```
- 默认访问 http://localhost:8800 （端口可用环境变量 `PORT` 覆盖）。
- 进程保活由 `watchdog.sh` / `keepalive.sh` 负责（沙箱环境每 10~20s 探活，失联自动拉起 app.py）。

## 关键点说明
- **数据源**：腾讯财经实时行情 `qt.gtimg.cn`（真实数据，无需 token）。本沙箱东方财富/新浪被封；腾讯日线接口 `ifzq.gtimg.cn` 部分时段不稳定（501），故 v3.10 起**自建本地日线库**（每交易日 15:05 自采），回测优先走本地库。
- **涨停扫描的历史条件受限**：你要求的"近一年涨停次数<15、昨日未涨停、5日振幅<17%"需历史数据，本地日线库积累满后即可支持，当前仍用**当日实时强度**（距涨停距离+量比+涨幅+委比）替代，并在界面注明。
- **预测回测闭环**：所有预测落盘 `pred_log.jsonl`，到期自动回填真实结果并累计 `pred_stats.json`；回测按"预测日期"从日线回溯，即使沙箱休眠跨天也不会拿错基准；腾讯日线故障时自动降级实时行情兜底。
- **候选池**：全市场主板首扫需约1分钟，构建期间接口即时返回"构建中"，完成后自动填充。
- 修改 `portfolio.json` 的 `take_profit_pct`/`pressure_pct`/`scan` 可自定义止盈/压力/筛选。

> 本平台为个人监控与异动辅助工具，所有预测/概率均基于规则与统计模型，**不构成投资建议**。

## ⚡ 性能基线（实测，Python 3.11）

尾盘高开潜力（gapup）已从「约 4 分钟且易卡死」优化到「约 2 秒稳定出结果」：

| 阶段 | 优化前 | 当前 |
|------|--------|------|
| `universe` 全市场扫描（3001 只） | 串行 8 只/请求，约 **173 秒** | 线程池并行 + 批量 40 只，**约 1 秒** |
| `top15` 拉分时算尾盘 | 串行，约 30-60 秒 | 线程池并行，**数秒** |
| AI 精修 | 本地模型逐只推理，**卡死/超时回退** | **默认跳过本地模型**（沙箱无 GPU 不稳定），仅远程 AI（无则回退启发式） |
| 端到端 | ~4 分钟 + 卡死 | **~2 秒**（`done, 5 rows`） |

> 优化点：行情抓取统一走 `fetch_tencent`，内部批量切分 + 线程池并发 + `requests.Session` 复用；全局共享线程池避免线程堆积；`/api/snapshot` 加超时保护防止接口挂起。**本地 AI 精修因沙箱环境不稳定已默认关闭**，如需恢复，配置远程 AI API 即可启用远程精修。

选股池每日扫描经全主板日线库预热后改读本地库（零网络），日常数秒级出结果；首扫或本地库覆盖不足时回退在线抓取，约数分钟。

## ⚠️ 部署与数据保护（务必遵守）

运行时数据（前端实时编辑 / 服务累积生成，已从 git 忽略）：`portfolio.json`、`gapup_log.jsonl`、`gapup_stats.json`、`gapup_weights_tuned.json`、`gapup_calib.json`、`pred_log.jsonl`、`pred_stats.json`、`daily_bars.jsonl`，模板为 `portfolio.json.example`。

**发布流程（关键防护：先同步线上数据再发布）**：

- 发布前必须先同步线上持仓，避免用本地旧数据顶掉用户在前端改的最新持仓：
  1. `GET /api/portfolio` 拉取线上完整持仓（含 `buy_date` / 阈值等）；
  2. 仅以线上 `holdings` 覆盖本地 `portfolio.json`，顶层字段（owner / settings / closed_positions / watchlist 等）保留本地值；
  3. 发布后再次 `GET` 校验，不一致则用备份 `POST` 还原。
- 线上持仓备份放在项目外独立目录（勿随部署包一起带走，否则失去备份意义）。

严禁以下操作（会拿陈旧基线顶掉线上用户数据）：
- ❌ `git checkout -- portfolio.json` / `git commit -A`（会恢复或提交陈旧持仓）
- ❌ 未先同步线上持仓就直接整目录发布（本地旧文件会顶掉线上）

> `deploy.sh` 为发布包装脚本：先拉取线上运行时数据（持仓/回测）写回本地，再调用发布，避免用陈旧基线覆盖用户改动；推送 GitHub 默认关闭（沙箱禁对外请求），源码请以本地仓库提交后推送。`/api/portfolio` GET 返回完整持仓（含 `buy_date`）便于忠实同步还原。
